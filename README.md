# Todo App

A simple Todo App built with React and CSS to help users manage daily tasks.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and responsive interface

## Technologies Used

* React
* JavaScript
* CSS

## What I Learned

Through this project, I practiced:

* React components
* State management
* Event handling
* Working with lists and user input
* Building interactive web applications

## Getting Started

1. Clone the repository
2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm start
```
